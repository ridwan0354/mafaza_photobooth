📸 Hardware Shutter & Hotshoe Flash Sync 🔄 Memeriksa Kamera & Sony Remote...

Kamera Sony A7III / Canon EOS & Trigger Flash Eksternal (Godox / Speedlight)

Agar lampu Flash / Trigger Godox di atas kamera ikut menyala saat hitungan mundur mencapai 0, sistem akan menembakkan Shutter Fisik Kamera via USB.

💡 Checklist Wajib di Menu Kamera Sony A7III agar Flash / Godox Menyala:
1. Hubungkan Kabel USB-C ke MacBook/PC:
Buka Menu ➔ Network1 ➔ PC Remote Function ➔ ON (Method: USB). Lalu klik tombol "🚀 Buka Sony Imaging Edge Remote" di atas.
2. Agar Live View Tidak Gelap Saat Pakai Flash Studio:
Buka Menu ➔ Camera2 (Ungu) ➔ Live View Display ➔ Setting Effect OFF (Supaya layar tetap terang walau speed 1/160s & f/8).
3. Pengaturan Flash di Sony A7III:
Pasang Trigger Godox/Speedlight di Hotshoe, pastikan Flash Mode = Fill-flash (⚡) dan WL (Wireless Flash) = ON.

🖨️ Bagaimana Cara Kerja Fitur Print di Windows, MacBook & Android?

1. Di Windows 10 & 11 Menggunakan Windows Native PrintDocument (.NET) & flag --kiosk-printing. Saat tombol Cetak ditekan, foto langsung dikirim ke antrean printer Windows (Epson, Canon, DNP, HP) dan memunculkan jendela status antrean cetak Windows secara otomatis.
2. Di Android (Tablet & HP) Mendukung Dual-Print Mode:
• Via Server Wi-Fi: Ketuk Cetak di Android ➔ otomatis mencetak di printer yang tercolok ke Laptop/PC Server.
• Via Android Langsung: Ketuk "🖨️ Cetak Perangkat" untuk mencetak langsung dari Android ke printer Wi-Fi Direct / Mopria / Bluetooth.
3. Di MacBook / macOS Menggunakan CUPS Direct Spooler (`lp`) yang memprioritaskan printer berstatus Online dan otomatis memunculkan ikon Pusat Cetak (Print Center) di Menu Bar kanan atas MacBook.
